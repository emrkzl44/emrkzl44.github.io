Part 3 · What does it cost?

A switch is fast, but not free

~1.2–2.2 µs
for one switch between Linux threads
(Bendersky, 2018)
  • Save and load registers
  • Jump into the kernel and back
  • Thousands of switches per second add up
10
Part 3 · What does it cost?

The hidden cost: a cold cache

A's data
B needs new data
  • The cache is full of A's data
  • B gets cache misses → slower
  • Often bigger than the direct cost (Li et al., 2007)
Hardware got faster, but OS work like switching did not keep up — Ousterhout, 1990
